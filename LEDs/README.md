This directory holds LED labs and project files. It's a mix of LibreOffice docs, Markdown docs, and MicroPython code, but all are free formats created with free software.

Some of the documents (e.g. SuperMini-MicroPython.md, SuperMini-MicroPython-NeoPixel.md, etc.) are structured around a particular microcontroller board. Different boards can be used, but the code will need to be modified to account for differences.
