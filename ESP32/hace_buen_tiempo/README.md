# Hace Buen Tiempo (It's Nice Weather)
This is a project for the ESP32-S3 microcontroller. Your goal is to use the sample code provided and create a MicroPython program of your own that will change the color of the WS2812B NeoPixel to a color that indicates relative comfort based on the temperature. For bonus points, you can factor in humidity readings to calculate a "feels like" temperature.

Create your program as main.py, so it will run whenever the ESP32-S3 is started.
